# Portao_POO_STM32

Projeto de controle de portão usando STM32 com programação orientada a objetos.

## Descrição
Este projeto implementa um sistema de controle para portão utilizando microcontrolador STM32 e conceitos de programação orientada a objetos.

## Estrutura do Projeto
- `src/` - Código fonte principal
- `lib/` - Bibliotecas customizadas
- `include/` - Arquivos de cabeçalho
- `platformio.ini` - Configurações do PlatformIO

## Como usar
1. Abra o projeto no PlatformIO
2. Compile o projeto
3. Faça o upload para o STM32

## Tecnologias
- STM32
- PlatformIO
- C++
